# Журнал принятых решений

- Методичка прочитана (metodichka.pdf, КубГТУ, 2019). Активизация по методичке: d = c·F, затем min(d, μ(x)) — так и реализовано.
- Язык: Python 3.10+; запуск GUI проверен на python3.12 (в окружении python3.13 нет tkinter).
- Кодирование хромосомы: перестановка клиентов 1..N с K−1 разделителями (гены N+1..N+K−1). Позволяет явно задавать и распределение по машинам, и порядок объезда; OX работает без доработок; мутация «перенос клиента» естественна. «Гигантский тур + split» отклонён: он сам гарантирует допустимость по вместимости, тогда штраф и переменная «Загрузка» теряют смысл, а число машин может превысить K.
- Нечёткие входы вычисляются для решения в целом (а не по маршрутам с усреднением): сбалансированность по определению межмаршрутная, а суммарные показатели проще интерпретировать диспетчеру.
- Перегрузка штрафуется вне нечёткого блока: fitness = Q − (1 + превышение/вместимость) при наличии перегруза, т.е. любое недопустимое решение хуже любого допустимого, но среди недопустимых сохраняется градиент.
- Временные окна — мягкие ограничения (опоздание допускается, но ухудшает нечёткую оценку), вместимость — жёсткое.
- Объём записки 30–40 с. считается без приложений (полный листинг кода в приложении А занимает много страниц); в реферате указывается полный объём.
- ГОСТ 2.105-95 заменён ГОСТ 2.105-2019 (действует с 01.02.2020); по требованию методички «проверить действие ссылочных стандартов» в нормативных ссылках указан действующий ГОСТ 2.105-2019.
