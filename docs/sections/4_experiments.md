# 4 Экспериментальный анализ

## 4.1 Методика экспериментов

Все эксперименты выполняются одной командой (скрипт experiments/run_experiments.py, около {{total_time}} с на четырёхъядерном процессоре). Задачи и алгоритмы используют фиксированные seed, поэтому повторный запуск даёт те же значения приспособленности (время работы может немного отличаться).

Для каждого размера N ∈ {10, 20, 30, 50} сгенерировано пять задач (число машин K = 2, 3, 4 и 7 соответственно). Сравниваются четыре метода:

- случайное решение – средние показатели 20 случайных хромосом;
- жадный алгоритм «ближайший сосед» с учётом вместимости;
- ГА со взвешенной суммой тех же нормированных показателей вместо нечёткого блока (веса 0,35; 0,30; 0,20; 0,15 для протяжённости, окон, срочности и сбалансированности) и тем же штрафом за перегруз:

!eq ws | weighted

- предлагаемый ГА с нечёткой оценкой (P = 100, 300 поколений при N ≤ 30 и 500 при N = 50, останов по стагнации 150 поколений).

Все планы оцениваются одной нечёткой моделью Q и «сырыми» показателями.

Выводы по эксперименту:

- оба варианта ГА многократно превосходят случайное решение и жадный алгоритм по соблюдению временных окон: при N = 50 суммарное опоздание сокращается с {{c50_nn_latemin}} мин у «ближайшего соседа» до {{c50_fz_latemin}} мин у ГА с нечёткой оценкой (на {{red_latemin_50}} %), число опоздавших клиентов – с {{c50_nn_late}} до {{c50_fz_late}};
- при N ≤ 30 ГА с нечёткой оценкой одновременно сокращает и пробег (на 3–5 % относительно жадного алгоритма), то есть строит планы, лучшие по всем критериям; при N = 50 пробег возрастает на {{dist_vs_nn_50}} % – это цена за практически полное устранение опозданий и выравнивание нагрузки водителей (B = {{c50_fz_bal}} против {{c50_nn_bal}});
- нечёткая оценка вырастает на 0,21–0,29 по сравнению с жадным алгоритмом; перегрузов в решениях ГА нет – штраф надёжно удерживает поиск в допустимой области;
- ГА со взвешенной суммой даёт сопоставимые результаты: по нечёткой оценке Q он немного уступает (например, {{c50_ws_q}} против {{c50_fz_q}} при N = 50), а по пробегу выигрывает, поскольку вес пробега в свёртке наибольший. Различие отражает разные «предпочтения» двух моделей оценки: нечёткая модель по правилам 19–24 сильнее ценит равномерную нагрузку водителей и не позволяет экономии пробега компенсировать опоздания. Преимущество нечёткой модели, таким образом, не в «более высоком числе», а в том, что её предпочтения заданы явными, проверяемыми экспертом правилами, а оценка объясняется протоколом вывода (подраздел 4.6);
- время работы ГА – от {{c10_fz_time}} до {{c50_fz_time}} с, что приемлемо для ежедневного планирования.

## 4.3 Сравнение с полным перебором

Для проверки того, насколько близко ГА подходит к оптимуму, сгенерированы задачи с N = 5…8 клиентами и K = 2 машинами, для которых функция приспособленности максимизирована полным перебором всех различных планов (с точностью до перенумерации машин). ГА с параметрами по умолчанию запускался десять раз с разными seed (таблица {tab:brute}).

!table brute | Сравнение ГА с полным перебором (10 запусков ГА) | gen:brute

При N = 5 и 6 ГА находит точный оптимум во всех запусках. При N = 7 и 8 оптимум найден в {{b7_hit}} % и {{b8_hit}} % запусков соответственно, а среднее отставание от оптимума составляет {{b7_gap}} % и {{b8_gap}} %. При N = 8 ГА вычисляет приспособленность лишь {{b8_ev}} уникальных особей – {{b8_evpct}} % от {{b8_sol}} вариантов полного перебора – и работает примерно в {{b8_speed}} раз быстрее перебора; с ростом N это соотношение быстро растёт в пользу ГА (подраздел 1.3). Это подтверждает положение подраздела 2.3: ГА находит оптимальное или близкое к нему решение, но не гарантирует оптимума в каждом запуске; для надёжности ГА можно запускать несколько раз с разными seed.

## 4.4 Сходимость генетического алгоритма

На рисунке {fig:conv} показана динамика приспособленности для задачи N = 30. В начальной популяции средняя приспособленность отрицательна (большинство случайных особей перегружены), но за 10–15 поколений популяция переходит в допустимую область. Лучшая приспособленность растёт ступенчато от {{conv_init}} до {{conv_best}} ({{conv_50}} к 50-му поколению); дальнейший рост связан с устранением последних опозданий. Разрыв между лучшей и средней приспособленностью сохраняется – мутации поддерживают разнообразие, преждевременной сходимости нет.

## 4.5 Влияние параметров генетического алгоритма

Исследовано влияние размера популяции, вероятности мутации и типа отбора на итоговую приспособленность при фиксированном числе поколений (300, без останова по стагнации). Каждая конфигурация запускалась на восьми задачах с N = 30; остальные параметры – по умолчанию. Средние значения итоговой приспособленности и их разброс показаны на рисунке {fig:params} (полная таблица – файл experiments/results/exp4_params.csv).

!fig params | experiments/results/exp4_params.png | 16 | Влияние параметров ГА: итоговая приспособленность (вверху) и средние кривые сходимости (внизу)

Выводы по эксперименту:

- **размер популяции**: при P = 20 и 50 не хватает разнообразия ({{p_pop_20}} и {{p_pop_50}}), лучший результат – при P = 100 ({{p_pop_100}}); при P = 200 ({{p_pop_200}}) лучшие решения распространяются медленнее, за 300 поколений поиск не завершается, а время удваивается;
- **вероятность мутации**: при p_{m} = 0,01 – преждевременная сходимость ({{p_pm_001}}); с ростом p_{m} результат улучшается до {{p_pm_02}} при 0,2, а при 0,3 снижается ({{p_pm_03}}) – частые мутации разрушают удачные фрагменты маршрутов;
- **тип отбора**: турнирный ({{p_sel_t}}) значительно лучше рулеточного ({{p_sel_r}}) и рангового ({{p_sel_k}}): приспособленности лежат в узком диапазоне 0,4–0,8, поэтому рулетка выбирает родителей почти равновероятно, а линейный ранговый отбор при P = 100 тоже создаёт слабое давление; турнир не зависит от масштаба значений.

Разброс между задачами (СКО 0,04–0,07) сопоставим с разницей близких конфигураций, поэтому выводы относятся к тенденциям.
