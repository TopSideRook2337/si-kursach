# Гибридная интеллектуальная система планирования маршрутов доставки

Курсовая работа по дисциплине «Системы искусственного интеллекта».
Генетический алгоритм ищет решение задачи маршрутизации транспорта с
временными окнами (распределение заказов по машинам + порядок объезда), а
нечёткий вывод Мамдани оценивает качество каждого решения — эта оценка и
есть функция приспособленности ГА. Оба метода реализованы с нуля.

## Установка

```bash
pip install -r requirements.txt
```

Нужен Python 3.10+. Для GUI нужен tkinter (в Linux: `sudo apt install python3-tk`).

## Запуск

```bash
python -m src.main --clients 30 --seed 1 --trace --plot routes.png   # консоль
python -m src.gui                                                    # окно программы
python experiments/run_experiments.py                                 # все эксперименты (~5 мин)
python -m pytest                                                     # тесты
python docs/build_report.py                                          # сборка записки .docx + .pdf
```

Готовая записка: `docs/Пояснительная_записка.docx` (и PDF-копия). Для сборки PDF и нумерации
содержания нужен LibreOffice с модулем Math (`sudo apt install libreoffice-writer libreoffice-math`);
без него `python docs/build_report.py --no-pdf` соберёт только docx (содержание обновится при
открытии в Word). Перед сдачей заполните поля `[ФИО]`, `[группа]` и т.п. на титуле и в задании
и вставьте скриншоты на места заглушек `[СКРИНШОТ: …]` в подразделе 4.7.

Основные параметры CLI: `--clients`, `--vehicles`, `--seed`, `--instance file.json`,
`--pop`, `--generations`, `--pc`, `--pm`, `--selection {tournament,roulette,rank}`,
`--fitness {fuzzy,weighted}`. Полный список — `python -m src.main -h`.

## Структура

| Путь | Содержание |
|---|---|
| `src/model.py` | клиенты, задача, решение, моделирование маршрута, метрики |
| `src/generator.py` | генератор задач с фиксированным seed (JSON) |
| `src/fuzzy/` | функции принадлежности, лингвистические переменные, 26 правил, вывод Мамдани |
| `src/ga/` | кодирование, операторы, нечёткая приспособленность, цикл ГА |
| `src/baselines.py` | случайное решение, «ближайший сосед», полный перебор (N ≤ 8) |
| `src/visualize.py`, `src/gui.py`, `src/main.py` | графики, окно tkinter, консольный запуск |
| `experiments/` | скрипт экспериментов, задачи (JSON), результаты (PNG, CSV) |
| `docs/` | пояснительная записка и скрипт её сборки |
| `DEFENSE.md` | вопросы к защите с ответами |
| `DECISIONS.md` | журнал принятых решений |
