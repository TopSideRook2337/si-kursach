#* ТЕРМИНЫ, ОПРЕДЕЛЕНИЯ И СОКРАЩЕНИЯ

В настоящей пояснительной записке применяют следующие термины с соответствующими определениями и сокращения.

!deflist 4.5,12
| Аккумуляция | Этап нечёткого вывода: объединение (операция max) активизированных нечётких множеств всех правил в одно множество выходной переменной |
| Активизация | Этап нечёткого вывода: вычисление степени истинности заключения правила с учётом весового коэффициента и «срез» функции принадлежности терма заключения |
| ГА | Генетический алгоритм – эвристический метод поиска, имитирующий естественный отбор: популяция решений улучшается операторами отбора, скрещивания и мутации |
| Дефаззификация | Переход от нечёткого множества к чёткому числу; в работе – метод центра тяжести |
| Лингвистическая переменная | Переменная, значениями которой являются слова (термы), каждое из которых задано нечётким множеством |
| ЛПР | Лицо, принимающее решение (диспетчер, логист службы доставки) |
| Приспособленность | Числовая оценка качества особи, по которой ведётся отбор в ГА |
| Терм | Значение лингвистической переменной («короткая», «средняя», «длинная») |
| Фаззификация | Вычисление степеней принадлежности чётких входных значений термам лингвистических переменных |
| Функция принадлежности | Функция μ(x) ∈ [0; 1], задающая степень принадлежности элемента x нечёткому множеству |
| CVRP | Capacitated Vehicle Routing Problem – задача маршрутизации с ограничением вместимости |
| OX | Упорядоченное скрещивание (Order Crossover) – оператор скрещивания для перестановок |
| VRP | Vehicle Routing Problem – задача маршрутизации транспортных средств |
| VRPTW | Vehicle Routing Problem with Time Windows – задача маршрутизации с временными окнами |
